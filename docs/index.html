二、深度观察专栏

中东地缘冲突升级：油价冲击与全球市场的“滞胀”阴影

    事件概述

    本周末，中东局势急剧恶化。胡塞武装宣称对沙特境内石油设施发动袭击，作为对美军空袭的报复，布伦特原油一度触及100美元/桶。与此同时，美伊停火协议名存实亡，美军对伊朗的打击行动暂止，但“外围”战火蔓延。CNN、路透社、彭博社、香港《信报》、台湾《经济日报》等多家媒体密集报道，高盛研判油价可能突破120美元，摩根大通预测三个月后布油或见114美元。此外，中国正推动巴基斯坦探索重启美伊谈判的途径，油价在该消息影响下短暂回落，但地缘风险溢价仍处高位。

    深层分析

  • 供需双重冲击：供给侧方面，红海封锁、霍尔木兹海峡紧张及黑海战火导致多条石油运输线受阻。需求侧上，全球库存处于低位，炼厂产能紧张。OilPrice.com指出“市场过剩叙事已被打破”，而CNN分析称“战争正在打破所有约束”。
  • 通胀传导与央行困境：油价飙升重燃通胀威胁，全球债券市场遭遇重创，美国长期国债收益率跃升至特朗普第二任期以来最高水平。欧洲央行拉加德警告能源风险，市场押注9月加息。美联储面临“通胀粘性”与“经济放缓”的两难，7月决议加息概率骤升。Wolf Street、NYT等分析指出，债市已向美联储发出明确警告。
  • 地缘政治博弈：美伊冲突背后是中美俄大国的角力。中国推动巴基斯坦斡旋，美国则面临国内政治压力——Politico分析称，油价上涨是特朗普第二任期面临的最大危险。胡塞武装袭击沙特，既是对美军的报复，也反映出伊朗代理人战争外溢的风险。

    • 影响与前瞻

  • 短期油价易涨难跌：若霍尔木兹海峡封锁持续，布油突破100美元后将加速上行。高盛模型中，每多拖一个月油价涨8美元，这意味着年底前油价可能触及120—130美元。
  • 全球股市承压：科技股对利率敏感度最高，叠加本周美联储决议和科技巨头财报，市场波动将显著放大。美债收益率飙升已开始压制成长股估值，纳指上周五已下跌2.15%。
  • 资产配置转向防御：Jamie Dimon的“不买股票/美债”言论加剧避险情绪，黄金虽短期跌破4050美元，但89%央行计划加仓，长期仍受支撑。防御性高股息资产（如中国红利低波）和能源股可能受益。
  • 中国政策应对：国内方面，光大证券认为A股处于牛市中途的震荡筑底阶段，油价冲击可能加速二次探底，但政策托底（增持回购、北向资金）提供缓冲。长鑫科技上市、方星海被查等事件将影响市场微观结构。

    • 总体而言，中东地缘冲突已成为当前全球市场最核心的风险变量，其演变将直接影响通胀预期、央行政策路径和风险资产定价。本周美联储决议和科技股财报将成为检验市场韧性的关键窗口。
