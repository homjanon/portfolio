二、深度观察专栏

Anthropic研究员称借助AI破解黎曼猜想，系"千禧年七大数学难题"之一

法新社的消息称，土耳其裔美国研究员、同时也是 Anthropic 员工莱文特·阿尔珀格（Levent Alpöge）周五（11月20日）表示，在 Anthropic 人工智能模型的帮助下，他已经证明了黎曼猜想。许多人认为，这是世界上最重要的数学难题之一。阿尔珀格周五仅在个人网站上发布了有关这项研究的叙述性说明，而非完整证明。据他介绍，这份证明超过25万页，目前尚未得到其他数学家的验证。此外，阿尔珀格仅表示，他使用的是 Claude 人工智能界面，但未说明具体版本。

然而，数小时后，斯坦福大学数学教授拉维·瓦基尔（Ravi Vakil）透露，同校一名博士后研究员也独立提交了自己的证明。法新社联系了两人，但截至目前尚未获得回应。

黎曼猜想由德国数学家伯恩哈德·黎曼（Bernhard Riemann）于1859年提出，涉及素数分布规律。大量数学定理和算法都以这一猜想为基础。黎曼猜想也是所谓"千禧年七大数学难题"之一。该名单由克雷数学研究所（Clay Mathematics Institute）于2000年设立，并承诺向每一个被解决的问题提供100万美元奖金。七大难题中还包括纳维-斯托克斯方程。2026年9月初，OpenAI 的一个人工智能模型在不到四天时间内解决了这一问题，在数学界引发巨大震动。

自去年以来，人工智能能力的提升已经推动数学领域接连取得突破。除了纳维-斯托克斯方程之外，OpenAI 还在10月初宣布解决了377个不同的数学问题。

纽约大学（NYU）教授内斯托尔·吉延（Nestor Guillen）分析称："这一结果本身不会立即产生影响，但它带来的理解将会在未来数月乃至数年中产生大量应用。"一些观察人士认为，这项证明显示出人工智能正在变得愈发强大，同时也意味着相关风险正在增加。相比纳维-斯托克斯方程的案例，内斯托尔·吉延认为此次事件更具积极意义。因为黎曼猜想的证明，是研究人员在人工智能模型协助下完成的成果，而并非完全由人工智能独立产出。在他看来，"这种方式更加尊重科学方法和科学实践。"

（法广中文）
