  1. 英伟达为何再度下跌：英伟达连续第七个交易日下跌，创下2022年以来最长连跌纪录，股价跌近3%。分析师指出，英伟达财报即将公布，市场对其数据中心需求增速放缓存在担忧，同时AI数据中心面临的政治阻力日益加大，得州州长警告数据中心企业"自掘坟墓"。（Forbes）
  2. 美国国债干预只是"创可贴"：华尔街对财政部通过国债回购压低长端收益率的举措持怀疑态度。高盛、富国银行策略师认为，回购难以改变推动收益率走高的基本面因素——财政赤字扩大、通胀压力与经济增长韧性。城堡证券警告，此举本质上是"金融抑制"，可能削弱美元并加剧通胀。（Fortune）

  9. 阿里巴巴发布万相3.0 AI视频模型：阿里巴巴在完成102亿美元股份配售后发布万相3.0 AI视频模型，股价随后下挫。市场分析认为巨额融资稀释股东权益，但AI布局显示公司长期战略决心。（Reuters）
